VELMORA — a vintage travel poster for a floating archipelago that does not exist: islands adrift above a glowing turquoise lagoon, waterfalls cascading upward into a violet-and-gold dusk, two small moons, and one lone sailboat. `main.ts` (Node 22, standard library only) deterministically writes the poster to `/output/entry.png` (1024×1024 PNG, 541,138 bytes).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
